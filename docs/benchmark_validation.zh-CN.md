## 已验证内容

- 3000 题的问题、按序选项与原答案可精确重建，且匹配独立下载的标注。
- 2153 个选中文件齐全，无额外媒体；下载回执的大小与 SHA256 一致，选中 ZIP 成员 CRC 通过。MMOU 视频和 MMAU 原始 Parquet 还匹配上游固定 LFS SHA256。
- ffprobe 检出有效流与正时长，所有选中视频都有音轨。音频为 954 WAV、46 MP3，原始字节不变，使用 `.audio` 文件名。
- 候选数保持可变：MMAU 为 2/4/5/8，Video-MME-v2 为 2/3/5/6/7/8，MMOU 为 10。
- 对实际 3000 行 manifest 的均匀分布 NLL/Brier 与解析值一致。这是合成评分检查，不是模型结果。
- CPU 测试覆盖动态标签、数值稳定、ECE、并列、缺失/非法预测、输入信息剔除、失败停止/恢复、ZIP 定向抽取与 Range 拒绝、源格式、processor FPS/patch 大小及时长警告。
- 官方 processor 对真实 WAV、MP3、带音轨视频各一个预检通过，含模板内标签 token 校验。视频仅用四帧和小像素预算做冒烟测试，不代表正式采样策略。未加载模型权重即可产生视频时间网格与音频特征。

预检使用 Transformers 5.13.1、qwen-omni-utils 0.0.9、librosa 0.11.0、audioread 3.0.1，不使用 librosa 1.0。空 FPS 列表省略；单视频采样 FPS 以兼容该 Transformers 的标量传递；patch 大小读取官方 processor。

## 保留的上游问题

九道 MMOU 题的视频不在固定媒体索引内，先排除再确定性采样，可选池为 4991 题。八个选中 MMOU 视频（影响 11 题）的文件时长与标注相差超过两秒，最大 44.739 秒；字节匹配上游 LFS。差异写入 `duration_warnings.json`，未静默替换字段、答案或视频。涉及时间的结论应使用实际解码时间，并先审查这些条目。

审计检查完整性和容器/流元信息，不是逐帧完整解码或人工答案核验。外部 `_SUCCESS` 仅认证数据审计。历史 [AV pilot](av_pilot.zh-CN.md) 当时通过 10 题 CPU 预检（154–3027 tokens），GPU 评分、隔离与缓存断言尚未执行；该历史状态不代表当前全部后端能力。
